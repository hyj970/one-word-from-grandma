The word is **THINGAMAJIG**. Ask a grandma what that new AI thing on her phone is and she will not say "large language model" — she will call it the thingamajig, in all caps, because that is what you call a clever little machine you do not quite understand but are fond of anyway. It is warm, baffled, funny in a single word, and unmistakably a grandmother's texting voice.

## Run it

```sh
python3 main.py
```

It writes the word deterministically to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). No randomness, no network, no model calls — the same word every run.
